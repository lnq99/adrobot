# Adrobot — ТЗ (оригинал)

> Источник: [Notion — Adrobot](https://app.notion.com/p/mnovikov/Adrobot-2b01eb78a7bb80a1b188c3a4a1cad55e)

Это тестовое задание покажет вам пример одной из систем, с которой мы работаем.

Эта система — рекламный трекер **Keitaro**, с его помощью мы отслеживаем
прибыльность наших рекламных объявлений. С технической точки зрения — это
конструктор ссылок, который редиректит пришедших пользователей согласно
настроенным правилам, а потом показывает статистику редиректов, например:

![Статистика Keitaro](./assets/CleanShot%202025-11-19%20at%2010.21.27@2x.png)

Ваша задача состоит из 2 частей.

## 1. «Создаватор» кампаний

Он должен принимать **название кампании**, **гео-код страны** и **ID оффера**
Keitaro и создавать кампанию, которая:

- имеет **2 потока**: первый поток ловит всех из указанной страны и редиректит
  на Google, второй поток редиректит на выбранный оффер;
- имеет настроенные **домен, группу и источник** (всё это тоже есть в API).

![Настройки потоков](./assets/CleanShot%202025-11-19%20at%2011.00.33.png)

Вот примерный интерфейс:

![Интерфейс создаватора](./assets/CleanShot%202025-11-19%20at%2011.02.42.png)

## 2. Редактор существующей кампании

Редактор должен уметь добавлять/удалять офферы в кампании. Этот редактор у нас
уже есть, ниже — видео, как это выглядит и как работает. Вам нужно воспроизвести
эту логику. Интерфейс — делайте на ваш вкус, главное, чтобы кнопки работали и
цифры были верные.

🎥 Видео-демо: <https://youtu.be/jNloscEWCjA>

## Как сдавать тестовое

Проект должен быть написан на **FastAPI + SQLAlchemy**. Фронт — можно сделать
любой, хоть React, хоть HTML-ки с кусками jQuery.

Сдавать работу в виде ссылки на GitHub с понятным README для миграций и запуска.
Использование агентов типа Cursor / Windsurf категорически приветствуется.
